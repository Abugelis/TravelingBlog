# Traveling Blog 

## Overview

This project was inspired by a real life traveling blog site. The goal for developing this site was to practice my front-end skills, learn to integrate JavaScript, and challenge myself with responsive design patterns.

## Features
- Responsive hero headers with reusable components
- Dynamically displayed blog post cards using JS 
- Contact page header carousel
- Responsive horizontal/hamburger multi-level navigation
- Contact/newsletter form integrated with a 3rd-party service
- Picture gallery with expandable images

## Installation
1. Clone the repo: `git clone https://github.com/Abugelis/TravelingBlog`
2. Open `index.html` in your browser
3. Or serve locally with a simple HTTP server

## Usage
- Navigate pages to see the reusable hero sections
- Resize the browser to see responsiveness
- Check blog posts template for consistency

## Challenges & Learnings
This project taught me a lot about:

- **Refactoring CSS**: I reduced multiple hero header styles into a single reusable component.
- **Consistency**: Using shared classes helped maintain visual language across pages.
- **Responsive design**: Learned `clamp()` and overlay positioning to handle different screen sizes.

Some struggles I had:

- Figuring out z-index for overlays initially broke content.
- Naming classes generically without over-engineering.
- Building multi-level navigation

## Future Improvements
- Optimize code further
- Implement lazy-loading for images to improve performance
- Enhance accessibility
